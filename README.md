# คลังบริบูรณ์ · ระบบทะเบียนครุภัณฑ์โรงเรียน

ระบบลงทะเบียนครุภัณฑ์ออนไลน์ฟรีสำหรับโรงเรียน โดย **ศรีโค้ดบูรณ์** (ครูแจ็ก)
ใช้บัญชีเดียวกับ [ตารางบริบูรณ์](https://github.com/sricodeboon/taraang-boriboon): สมัครที่นั่นแล้วเข้าระบบนี้ได้ทันที

- ออกเลขครุภัณฑ์อัตโนมัติตามรูปแบบของโรงเรียน (ค่าเริ่มต้น `7440-0109-0001/2569`) ซื้อหลายชิ้นได้เลขเรียงกัน รับเลขเดิมได้
- รูปถ่ายตัวเครื่อง/ป้ายเลขเครื่อง ย่อในมือถือก่อนอัปโหลด (2.6 MB → ~160 KB)
- สติกเกอร์ QR + บาร์โค้ด A4 หลายขนาด · สแกนด้วยกล้องมือถือหรือเครื่องยิงบาร์โค้ด
- ทะเบียนคุมทรัพย์สินแบบกรมบัญชีกลาง + ค่าเสื่อมราคาตาม ว 238 · ยืม/เบิก–คืน + ใบยืม · ตรวจนับประจำปี + รายงาน · สถานะตามระเบียบฯ 2560 หมวด 9
- หน้าภาพรวม: จำนวน มูลค่า สถานะ ประเภท ค้างคืน ความคืบหน้าตรวจนับ

เว็บ: https://sricodeboon.infinityfreeapp.com/khlang/ · แผนและเหตุผลทางระเบียบ: [docs/PLAN.md](docs/PLAN.md)

## ติดตั้ง

ต้องวางคู่กับ `timetable/` (ตารางบริบูรณ์) ในโดเมนเดียวกัน PHP 8.1+ (pdo_sqlite หรือ pdo_mysql, intl, gd แนะนำ)

```sh
php composer.phar install --no-dev      # mPDF + qrcode
php -S 127.0.0.1:8080 -t htdocs dev-router.php   # จากโฟลเดอร์เว็บหลัก
sh tools/build-zip.sh composer.phar      # สร้าง khlang.zip ขึ้นโฮสต์
```
