# คลังบริบูรณ์ · แผนกระบวนการทำงาน

ระบบทะเบียนครุภัณฑ์โรงเรียนของศรีโค้ดบูรณ์ ใช้ฐานข้อมูลและบัญชีผู้ใช้ร่วมกับ "ตารางบริบูรณ์"

## 1. กระบวนการทำงานของโรงเรียน (ตามวงจรพัสดุ)

```
 ได้มา ──► ลงทะเบียน ──► ติดสติกเกอร์ ──► ใช้งาน/ยืม–คืน ──► ตรวจนับประจำปี ──► ชำรุด/จำหน่าย
 (ซื้อ/รับบริจาค) (ออกเลขอัตโนมัติ    (QR/บาร์โค้ด)     (ใบยืม ข้อ 208)   (ข้อ 213 สแกน)     (ข้อ 214–218)
                  + รูป + เลขเครื่อง)
```

| ขั้น | ผู้ทำ | ในระบบ | เอกสารที่ได้ |
|---|---|---|---|
| 0. ตั้งค่าครั้งแรก | เจ้าหน้าที่พัสดุ | ตั้งค่า → รูปแบบเลข, ส่วนราชการ, ผู้ลงนาม, กรรมการตรวจสอบ | – |
| 1. ลงทะเบียน | เจ้าหน้าที่พัสดุ | ลงทะเบียน → เลือกชนิด ชื่อ ราคา วันที่ได้มา (ซื้อหลายชิ้นได้เลขเรียงกัน) · มีเลขเดิมกรอกเลขเดิมได้ | ทะเบียนคุมทรัพย์สิน (1 แผ่น/รายการ) |
| 2. ถ่ายรูป | ใครก็ได้ที่ถือมือถือ | ถ่ายตัวเครื่อง + ป้ายเลขเครื่อง ระบบย่อรูปในเครื่องก่อนส่ง | – |
| 3. ติดรหัส | เจ้าหน้าที่พัสดุ | พิมพ์ → สติกเกอร์ QR (A4 24/21/14/10 ดวง, เริ่มดวงไหนก็ได้) | สติกเกอร์ |
| 4. ยืม/เบิก–คืน | เจ้าหน้าที่พัสดุ | สแกน/ค้น → ยืม (กำหนดคืน, ผู้อนุมัติ) → รับคืน (สภาพเมื่อคืน) | ใบยืมพัสดุ |
| 5. ตรวจนับประจำปี | กรรมการ (ไม่ใช่เจ้าหน้าที่พัสดุ) | สแกน → โหมดตรวจนับ → ยืนยันพบ + สภาพ | รายงานผลการตรวจสอบพัสดุประจำปี |
| 6. ชำรุด/จำหน่าย | เจ้าหน้าที่พัสดุ | เปลี่ยนสถานะ ชำรุด → รอจำหน่าย → จำหน่ายแล้ว (บันทึกเลขหนังสือในเหตุผล) | ประวัติด้านหลังทะเบียนคุม |

## 2. ข้อกำหนดจากระเบียบ (ที่ระบบทำตาม)

- **เลขครุภัณฑ์**: ระเบียบไม่ได้กำหนดรูปแบบตายตัว (คู่มือ สพป.ขอนแก่น เขต 1) ส่วนที่ใช้ร่วมกันคือรหัส FSN กลุ่ม-ประเภท 4 หลัก
  ค่าเริ่มต้น `{cat}-{seq}/{fy}` เช่น `7440-0109-0001/2569` · ลำดับเริ่ม 0001 ใหม่ทุกปีงบประมาณแยกตามชนิด (แบบคู่มือ ตร.) เปลี่ยนเป็นนับต่อเนื่องได้
  ออกเลขในธุรกรรม `BEGIN IMMEDIATE` กันเลขซ้ำ · เลขที่ออกแล้วไม่เปลี่ยน · ปีงบประมาณ ต.ค.–ก.ย.
- **ทะเบียนคุมทรัพย์สิน**: แบบกรมบัญชีกลาง (หัวทะเบียน 10 ช่อง + ประเภทเงิน + วิธีการได้มา + ตาราง 12 คอลัมน์) ด้านหลังประวัติซ่อมบำรุง
- **ค่าเสื่อมราคา**: ว 238 (2557) เส้นตรง ค่าเสื่อม/ปี = ราคาทุน ÷ อายุ คงมูลค่า 1 บาท · ได้มาวันที่ 1–15 นับเดือนนั้น 16 ขึ้นไปนับเดือนถัดไป · ปิดรอบ 30 ก.ย.
  ตรวจกับตัวอย่างกรมประชาสัมพันธ์แล้วตรง (16,000 บาท 25 เม.ย. 62 อายุ 5 ปี → 1,333.33 / 3,200 ×4 / 1,865.67 เหลือ 1.00)
  เกณฑ์ครุภัณฑ์ (ว 43/2562): ปีงบฯ ≥2563 ≥10,000 · 2546–2562 ≥5,000 · 2540–2545 ≥30,000 · ต่ำกว่าเกณฑ์ลงทะเบียนคุมแต่ไม่คิดค่าเสื่อม
- **อายุการใช้งาน**: ตาราง สพฐ. (2547) ซึ่งอยู่ในช่วงของ ว 238 เก็บไว้ที่ครุภัณฑ์แต่ละชิ้น (แก้ตาราง master แล้วของเดิมไม่เปลี่ยน)
- **ยืม** ข้อ 207–211: ต้องมีหลักฐาน เหตุผล กำหนดคืน ผู้อนุมัติ · ผู้ยืมรับผิดชอบซ่อม/ชดใช้ (ข้อ 209 อยู่ในใบยืม) · ครบกำหนดแล้วทวงคืนภายใน 7 วัน (ข้อ 211 แสดงในหน้ายืม–คืน)
- **ตรวจสอบประจำปี** ข้อ 213 · **จำหน่าย** ข้อ 214–218 (สถานะ: ใช้งานได้ ชำรุด ส่งซ่อม เสื่อมสภาพ สูญไป ไม่จำเป็นต้องใช้ รอจำหน่าย จำหน่ายแล้ว)

## 3. สถาปัตยกรรม

- **ล็อกอินร่วม**: session ชื่อ `ttsid` path `/` ใช้ร่วมกับตารางบริบูรณ์ · ปุ่มเข้าสู่ระบบของระบบนี้ผ่าน `go.php` ตั้ง `tt_next=khlang` แล้วใช้ OAuth/โหมดทดลองของตารางบริบูรณ์ ตารางบริบูรณ์ส่งกลับมาด้วย `after_login()`
- **ฐานข้อมูลเดียวกัน**: อ่านค่า db จาก `timetable/config.php` · ตารางของระบบนี้ขึ้นต้น `kl_` · stamp migration อยู่ใน `kl_meta` (ห้ามแตะ `PRAGMA user_version` ของตารางบริบูรณ์)
- **รูปถ่าย**: ย่อในเบราว์เซอร์ (ด้านยาว ≤1280px JPEG ≤350KB) → เซิร์ฟเวอร์ตรวจชนิด/ขนาด ย่อซ้ำด้วย GD ถ้ายังใหญ่ → ไฟล์ใน `storage/photos/<โรงเรียน>/` ส่งผ่าน `photo.php` เฉพาะคนในโรงเรียน · รูปย่อ 160px เก็บในคอลัมน์ `thumb`
- **QR**: `s.php?t=<รหัสสุ่ม 10 ตัว>` · คนในโรงเรียน → หน้ารายละเอียด · คนทั่วไป → เลข ชื่อ หน่วยงาน สถานที่ สถานะ (ไม่มีราคา/เลขเครื่อง/ผู้ยืม) · บาร์โค้ด Code 128 ใช้รหัสเดียวกัน
- **สแกน**: BarcodeDetector ของเบราว์เซอร์ ถ้าไม่มี (iPhone Safari/Firefox) โหลด ZXing ในระบบ · เครื่องยิงบาร์โค้ดพิมพ์ลงช่องค้นหาได้
- **PDF**: mPDF ที่เซิร์ฟเวอร์ ฟอนต์ TH Sarabun New · ครั้งละ ≤300 รายการ

## 4. ขั้นต่อไปที่เสนอ

1. ทดลองกับโรงเรียนจริง 1 แห่ง (สติกเกอร์บนกระดาษจริง, สแกนด้วย iPhone/Android)
2. นำเข้าทะเบียนเดิมจาก Excel (โรงเรียนส่วนใหญ่มีทะเบียนเดิมเป็นไฟล์)
3. ประวัติซ่อมพร้อมจำนวนเงิน (ค่าใช้จ่าย/เพิ่มทุน) และขั้นตอนจำหน่ายแบบมีเลขหนังสือ/วันแจ้ง สตง.
4. เชิญครูคนอื่นเข้าร่วมโรงเรียน (ตอนนี้ 1 บัญชีต่อโรงเรียน เหมือนตารางบริบูรณ์)
